# 최신 제출 자료 검증 · 2026-11-02

## 0.4.0 반납 마무리 · 2026-11-02

차량·Flutter 0.4.0+15는 반납 마무리를 보완했습니다. 물건별 ‘챙겼어요’를 차량에서 확인하고 휴대폰으로 이어가며, 운영자가 등록한 주차장 입구·층·구역·주차면 안내를 봅니다. 사진 구도 가이드와 같은 항목의 인수·반납 비교, 계정·서버·기록별 암호화 임시 저장을 제공합니다. 배터리는 인수 때 실제 수신한 퍼센티지를 기준으로 부족분을 안내합니다.

Android Debug 100개·Release 98개, 서버 51개, Flutter 53개(선택 2개 제외), 분석 문제·Lint 오류0/기존 경고24. 읽기 전용 Pleos AVD의 새 반납 통합 11조건과 실제 웹 PNG/JPEG/WebP 선택·재시작 복구·직접 확인·최종 접수를 확인했습니다. 시험 배터리는 인수80%→반납72%, 기준80%·부족8%p였습니다.

충전 경유 요청은 실제 내비 경로에 전달되지만 해당 AVD의 경유지 조회 좌표는0,0입니다. 최종 목적지는 맞아도 충전 경유지는 앱에서 검증 완료로 표시하지 않고 내비에서 직접 확인하도록 안내합니다. 실차·정상 VIN Release 전체 흐름·Fold8 실물 촬영과 실제 단말 통신 단절은 미검증입니다. 새 영상은 올리지 않습니다.

## 0.3.0 음성 짐 메모·도착 후 반납 안내 · 2026-11-02

음성으로 짐을 메모하고 반납 장소 근처에서 확인 순서를 안내하는 차량·Flutter 0.3.0입니다. 차량 VIN·P 상태를 실제로 다시 읽고, 이용자가 확인한 장소·물건만 같은 예약의 메모로 저장합니다. 반납 점검을 저장하면 메모도 고정해 서버와 Flutter에 전달합니다.

도착 제안은 150m 안의 서로 다른 새 위치 2개(15초 이내)와 VIN/P 조회(8초 이내)를 요구합니다. ‘반납 준비 시작’을 선택하면 다시 확인하고 기존 반납 점검으로 이어집니다. 창문 → 저장한 짐 메모·점유 좌석 → 사진·직접 확인 순서를 유지하며 자동 저장·반납은 하지 않습니다.

Android Debug95/Release93, 서버45, Flutter43(선택2개 제외), 분석/Lint 오류0·기존 경고24. 읽기 전용 AVD와 별도 계정·DB에서 실제 SDK13조건을 통과했습니다. 한국어 생성 PCM을 공식 ON_DEVICE 입력 API로 보내 최종 인식을 확인했으며 호스트 마이크·실차 인식률 시험은 아닙니다. 이번 통합은 인수부터 반납 저장·동기화까지이고 사진·최종 접수 전체는 선행0.2.6 근거입니다.

## 이전 공개 시점의 검증 기록

# 구현과 검증 범위

차량 앱 0.2.6의 밝은 바탕·짙은 청록, 단계 표시·이용 요약·짐 메모·좌석 배치도를 적용했습니다. Android Debug 82/Release 80, Debug/Release 빌드, Lint 오류 0/기존 경고 24를 확인했습니다. 표시용 자료를 사용한 5조건 검토와 실제 SDK/음성 시험은 구분합니다.

좌석은 원시 정수 1=비점유, 2=점유, 0/잘못된 값=확인 불가로 판정합니다. SDK Boolean 변환의 의미 손실을 분리합니다. 실제 AVD에서 좌석 변화·callback을 확인했습니다. Pleos TTS는 ON_DEVICE 한국어를 사용하며 선행 0.2.5 시험에서 10조건·onStart/onDone·출력 PCM 비무음을 확인했습니다.

최신 체험 예약의 실제 SDK 인수/반납 관측을 보존하고 Flutter 웹 UI에서 생성 시험 사진 3장·직접 확인 3종·시험 메모·최종 접수를 완료했습니다. 서버 사진 디코딩과 차량·웹·서버 접수 번호 일치를 확인했습니다. 기존 다른 사용자와 기록, APK·서명 키를 보존했습니다. 이번 최종 접수에서 TTS를 다시 재생/측정한 것으로 주장하지 않습니다.

알려진 Debug AVD의 명시적 테스트 VIN과 생성 사진의 시험입니다. 실차·정상 SDK VIN·실폰 촬영·iOS와 제출용 Release 실행은 검증되지 않았습니다. 비점유는 소지품 없음이 아니며 사람과 짐을 구분하지 않습니다. 실제 업체 반납·정산을 처리하지 않습니다.

이 저장소는 소스와 일반 검증 설명만 공개합니다. 실제 신청서 개인정보, 사용자 DB·메일함·사진 원본·계정 토큰·개인 서명 키·작업 로그는 포함하지 않습니다.
