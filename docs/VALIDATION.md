## 이전 공개 시점의 검증 기록

# 구현과 검증 범위

차량 앱 0.2.6의 밝은 바탕·짙은 청록, 단계 표시·이용 요약·짐 메모·좌석 배치도를 적용했습니다. Android Debug 82/Release 80, Debug/Release 빌드, Lint 오류 0/기존 경고 24를 확인했습니다. 표시용 자료를 사용한 5조건 검토와 실제 SDK/음성 시험은 구분합니다.

좌석은 원시 정수 1=비점유, 2=점유, 0/잘못된 값=확인 불가로 판정합니다. SDK Boolean 변환의 의미 손실을 분리합니다. 실제 AVD에서 좌석 변화·callback을 확인했습니다. Pleos TTS는 ON_DEVICE 한국어를 사용하며 선행 0.2.5 시험에서 10조건·onStart/onDone·출력 PCM 비무음을 확인했습니다.

최신 체험 예약의 실제 SDK 인수/반납 관측을 보존하고 Flutter 웹 UI에서 생성 시험 사진 3장·직접 확인 3종·시험 메모·최종 접수를 완료했습니다. 서버 사진 디코딩과 차량·웹·서버 접수 번호 일치를 확인했습니다. 기존 다른 사용자와 기록, APK·서명 키를 보존했습니다. 이번 최종 접수에서 TTS를 다시 재생/측정한 것으로 주장하지 않습니다.

알려진 Debug AVD의 명시적 테스트 VIN과 생성 사진의 시험입니다. 실차·정상 SDK VIN·실폰 촬영·iOS와 제출용 Release 실행은 검증되지 않았습니다. 비점유는 소지품 없음이 아니며 사람과 짐을 구분하지 않습니다. 실제 업체 반납·정산을 처리하지 않습니다.

이 저장소는 소스와 일반 검증 설명만 공개합니다. 실제 신청서 개인정보, 사용자 DB·메일함·사진 원본·계정 토큰·개인 서명 키·작업 로그는 포함하지 않습니다.
